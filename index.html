📖 Sổ Tay Cú Pháp T-SQL Cốt Lõi

Tóm lược các cấu trúc lập trình trong học phần Cơ sở dữ liệu - Viện CNTT&TT:

1. KHAI BÁO BIẾN
DECLARE @TenHV NVARCHAR(50) = 'An';
SET @TenHV = 'Bình';
2. ĐIỀU KIỆN IF...ELSE
IF (@Diem >= 8.5) BEGIN PRINT 'Giỏi' END
ELSE BEGIN PRINT 'Đạt' END
3. VÒNG LẶP WHILE
WHILE (@i <= 100) BEGIN SET @i = @i + 1; END
4. BẮT LỖI TRANSACTION & TRY...CATCH
BEGIN TRY
  BEGIN TRANSACTION;
  INSERT INTO...
  COMMIT TRANSACTION;
END TRY
BEGIN CATCH
  ROLLBACK TRANSACTION;
END CATCH
5. CON TRỎ CURSOR
DECLARE cur CURSOR FOR SELECT MaHV FROM HOCVIEN;
OPEN cur; FETCH NEXT FROM cur INTO @MaHV;
WHILE @@FETCH_STATUS = 0 BEGIN ... FETCH NEXT ... END;
CLOSE cur; DEALLOCATE cur;

💻 Phiên Bản Desktop (Windows, macOS, Linux)

Dự án bao gồm 2 phiên bản ứng dụng máy tính nguyên bản (Native Desktop):

✨
1. Phiên bản Tkinter (Có sẵn trong Python, không cần cài đặt thêm):
Chạy ngay lập tức trên mọi hệ điều hành:
python3 desktop/app_tkinter.py
🚀
2. Phiên bản Qt6 (Giao diện cao cấp PyQt6 / PySide6):
Cài đặt thư viện và khởi chạy:
pip install -r desktop/requirements.txt
python3 desktop/app_qt.py
